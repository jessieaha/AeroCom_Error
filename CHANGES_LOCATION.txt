require_all semantics:
  If any required deposition species is missing for a model, dep_BC_OA /
  dep_total is None and that model gets no deposition-based lifetime
  (same rule as load_BC_OA / emi_BC_OA). Example: CAM5_CTRL2016 has depbc
  but no depoa → no dep_BC_OA lifetime.
